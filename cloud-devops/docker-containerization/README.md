***# Multi-Stage Docker Containerization \& Optimization***



***## Overview***



***This project demonstrates a multi-stage Docker setup for a Node.js + Express web application backed by PostgreSQL.***



***## Architecture***



***- Node.js 22***

***- Express 5***

***- PostgreSQL 17***

***- Docker Compose***

***- Multi-stage Docker build***

***- Alpine Linux runtime***

***- Non-root container user***

***- Docker health checks***

***- Persistent PostgreSQL volume***
